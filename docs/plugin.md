# Плагин KiCad

Кнопка «Ultimate Kicad Autorouter» в редакторе плат KiCad 8–10 (Action-плагин pcbnew).

## Установка

```bash
python tools/install_kicad_plugin.py              # найдёт папку плагинов самой новой версии KiCad
python tools/install_kicad_plugin.py <папка>      # или указать её явно
```

Скрипт кладёт в папку плагинов KiCad (`Документы/KiCad/<версия>/scripting/plugins` на Windows,
`~/.local/share/kicad/<версия>/scripting/plugins` на Linux) загрузчик со ссылкой на репозиторий.
После установки перезапустите редактор плат или выполните «Инструменты → Внешние плагины → Обновить плагины».

В Python, который входит в KiCad, нет numpy, shapely и scipy, поэтому трассировка запускается во внешнем Python.
Укажите его переменной окружения `UKA_PYTHON` (например, Python из виртуального окружения с
`requirements.txt`); без неё берётся `python3`/`python` из PATH.

## Работа

1. Сохраните плату. Если на ней уже есть трассы, плагин спросит, добавлять ли свои поверх.
2. Нажмите кнопку. Плагин:
   * сохраняет плату;
   * запускает `route_board.py` во внешнем Python с конфигом `<плата>.toml` рядом с платой, а если его нет —
     с настройками по умолчанию (`--no-drc`: DRC делаете вы в KiCad);
   * переносит в открытую плату трассы, переходы и полигоны питания, заливает зоны;
   * показывает, сколько добавлено и где отчёт.
3. Запустите DRC KiCad и проверьте результат.

## Проверено

Без интерфейса — Python KiCad 10 и `kicad-cli` (тест `tests/test_kicad_plugin.py`): плагин разводит
тестовую плату, переносит 248 отрезков, 77 переходов и 3 зоны, DRC KiCad не находит нарушений зазоров,
обрывов и неверных переходов. Нажатие кнопки в живом редакторе стоит проверить на своей установке.

## Если что-то не так

* «Ошибка трассировки» с текстом `ModuleNotFoundError` — внешний Python без зависимостей: задайте `UKA_PYTHON`.
* Кнопки нет — проверьте папку плагинов и консоль скриптов KiCad (Инструменты → Консоль скриптов).
* В KiCad 9+ размер перехода хранится в padstack, поэтому плагин копирует переходы целиком (`Duplicate`).
  Если переходы появились с нулевым диаметром, обновите плагин.
