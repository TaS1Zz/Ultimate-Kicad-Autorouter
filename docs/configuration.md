# Конфигурация

Все числа приходят из трёх мест — в порядке приоритета:

1. **Конфиг платы** `boards/*.toml` (TOML; пропущенные ключи берутся по умолчанию из `config.DEFAULTS`).
2. **Файлы KiCad**: контур из `Edge.Cuts`, толщина меди из `(stackup)` платы, зазоры, ширины и переходы
   из `.kicad_pro` рядом с платой (класс `Default` и `design_settings.rules`; берётся большее из проекта
   и значений по умолчанию).
3. **Значения по умолчанию** в `rules.py` (под возможности JLCPCB с запасом).

Пути в конфиге — относительно самого файла конфига. Имена цепей в таблицах можно задавать шаблонами `fnmatch`
(`"LED_K*"`); точное имя важнее шаблона.

## Пример

```toml
[board]
file = "../example/demo_board.kicad_pcb"

[power.currents]           # А
"+3V3"   = 0.15
"LED_K*" = 0.02

[power.loads]              # если задано — ток цепи = сумма потребителей
"VBUS" = { J2 = 1.0, U3 = 0.1, U2 = 0.05 }

[power.sources]
"VBUS" = "J1"
"+3V3" = "U3"              # или список: ["U8", "U9"]

[fanout]
refs = ["J1"]
[fanout.pins]
"J1" = ["A5", "A6", "A7", "B5", "B6", "B7"]

[nets]
fast = ["USB_D*"]
diff_pairs = [["USB_D+", "USB_D-", 90.0]]
```

## Справочник ключей

### `[board]`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `file` | — | Плата `.kicad_pcb` с расстановкой |

### `[rules]` — поверх `.kicad_pro`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `clearance` | 0,2 мм | Зазор медь–медь |
| `edge` | 0,5 мм | Медь–край платы |
| `track` | 0,25 мм | Ширина сигнальной трассы |
| `track_min` | 0,2 мм | Минимальная ширина (вторая ступень для сигналов и сужение у выводов) |
| `via_d`, `via_drill` | 0,6 / 0,3 мм | Переход |
| `gnd_stub` | [0,4, 0,3, 0,25] | Ширины отвода GND-площадки к переходу, по убыванию |

### `[stackup]` — если в плате нет `(stackup)`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `copper` | F/B 0,035, In1/In2 0,0175 мм | Толщина меди слоёв (1 oz снаружи, 0,5 oz внутри — JLC04161H-7628) |
| `dielectric` | F–In1 0,2104 мм εr 4,4; In1–In2 1,065 мм εr 4,6; In2–B 0,2104 мм εr 4,4 | Диэлектрики между слоями: `{between = [a, b], h, er}` |
| `planes` | [] — авто | Слои-плоскости. Авто: внутренний слой, где есть только зоны цепи GND |

### `[power]`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `currents` | {} | Ток цепи, А. Если таблица задана, остальные цепи — сигнальные. Если не задана — встроенные правила: `VBUS*` 1 А, `+5V` 1 А, `+3V3` 0,3 А |
| `nominal` | {} | Номинальное напряжение, В. Иначе по имени: 5V/VBUS → 5, 3V3 → 3,3, 1V8 → 1,8, 12V → 12 |
| `loads` | {} | Потребители `{цепь = {ref = А}}`. Ток цепи = сумма; используются в расчёте падения напряжения |
| `sources` | {} | Откуда втекает ток: ref или список ref. Без источника падение по меди не считается |
| `polygon_current` | 1,0 А | С этого тока цепь получает полигон |
| `polygon_margin` | 0,8 мм | Насколько полигон шире трассы с каждой стороны |

Цепь считается **питанием** (широкая трасса, разводится до сигналов, защищена при переразводке) при токе от 0,3 А.
Ширина питания: максимум из нагрева (IPC-2221, ΔT = 10 °C) и падения 2 % номинала; не шире 1 мм (`rules.WMAX`).

### `[fanout]`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `auto` | true | Микросхемы `U*` с ≥ 4 SMD-выводами шириной ≤ 0,35 мм находятся сами |
| `mode` | `"power"` | `power` — на переходы выводятся только выводы GND и питания (цепи с номиналом); `all` — все выводы (плотные BGA/QFN) |
| `refs` | [] | Дополнительно (разъёмы), все выводы с цепью |
| `pins` | {} | Только эти выводы: `{ref = [номера]}` |
| `exclude` | {} | Не выводить: `{ref = [номера]}` |

### `[thermal]` — переходы под открытыми площадками

| Ключ | По умолчанию | Описание |
|---|---|---|
| `auto` | true | GND-площадки микросхем `U*` площадью больше 4 мм² |
| `pitch` | 1,5 мм | Шаг сетки переходов |
| `refs` | [] | Ограничить этими микросхемами |

### `[nets]`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `fast` | [] | Быстрые цепи: только слой с опорной плоскостью рядом (+ короткий выход у своих площадок) |
| `diff_pairs` | [] | `[[P, N, Zdiff]]`, Zdiff по умолчанию 90 Ом |
| `skew_max` | 0,15 мм | Допустимая разница длин проводников пары |
| `pair_gap_min` | 0 | Минимальный зазор внутри пары; 0 — общий зазор платы. Если меньше общего, рядом с платой пишется `.kicad_dru` |
| `order_first` | [] | Эти сигнальные цепи разводятся первыми |

### `[route]`, `[drc]`

| Ключ | По умолчанию | Описание |
|---|---|---|
| `route.negotiate_iters` | 30 | Максимум проходов PathFinder (останов раньше — после 5 проходов без улучшения) |
| `route.threads` | 0 | Потоков; 0 — по числу ядер |
| `drc.loop` | true | DRC KiCad в цикле с исправлениями |
| `drc.iters` | 3 | Повторов исправления |

## Параметры поиска — переменные окружения

Задаются в `route2.py`; любой можно переопределить без правки кода: `set ROUTER_VIAC=80` (Windows) или
`ROUTER_VIAC=80 python route_board.py …`. Длины — в клетках по 0,1 мм, если не указано иное.

| Параметр | Значение | Смысл |
|---|---|---|
| `ROUTER_B45`, `ROUTER_B90` | 12 / 30 | Штраф излома 45° / 90° |
| `ROUTER_VIAC` | 60 | Цена перехода (6 мм пути) |
| `ROUTER_SMOOTH_BEND` | 40 | Цена излома 45° при спрямлении (90° — ×2,2) |
| `ROUTER_LANE_COST` | 0,3 | Надбавка за клетку вне полосы шины |
| `ROUTER_LANE_R` | 1,6 мм | Радиус действия полосы |
| `ROUTER_LANE_HW` | 1,5 | Вес эвристики при поиске с полосой или перегрузкой (взвешенный A*) |
| `ROUTER_PAIR_COST` | 2,0 | Надбавка за клетку вне полосы дифпары |
| `ROUTER_NECK_R` | 0,8 мм | Зона сужения вокруг узкой площадки |
| `ROUTER_THERMAL_KEEP` | 0,3 мм | Отступ чужих трасс от штыревых GND-площадок на F/B |
| `ROUTER_PF0`, `ROUTER_PF_MUL` | 0,6 / 1,6 | PathFinder: начальная цена чужой территории и её рост за проход (потолок 50) |
| `ROUTER_HINC` | 0,6 | PathFinder: прибавка истории в клетке конфликта |
| `ROUTER_ESC_COST` | 4,0 | Цена клетки чужого коридора выхода |
| `ROUTER_ESC_LEN` | 1,2 мм | Длина коридора выхода за край площадки |

Цена направлений по слоям (`DIRC`, множители горизонталь / вертикаль / диагональ): F 1,0 / 1,5 / 1,25,
In2 1,0 / 2,0 / 1,5, B 2,0 / 1,0 / 1,5.

Что крутить:
* Много переходов — поднять `ROUTER_VIAC` (80–100).
* Шины слишком рыхлые — поднять `ROUTER_LANE_COST` (0,4–0,6); слишком много переходов в шинах — опустить (0,2).
* Ломаные трассы — поднять `ROUTER_SMOOTH_BEND` или `ROUTER_B45`.
